# Anna Kuznetsova — Portfolio Site

Personal research portfolio, built as a static site.

## Contents

- `index.html` — the site
- `portrait.jpg` — profile photo used in the hero section

## Live site

Once published via GitHub Pages, the site is available at:

`https://<your-username>.github.io/<repo-name>/`

(or `https://<your-username>.github.io/` if this repo is named `<your-username>.github.io`)

## Updating the site

1. Edit `index.html` directly, or replace `portrait.jpg` with a new photo (keep the same filename, or update the `<img src="...">` reference in `index.html` to match).
2. Commit and push the change (or use "Upload files" in the GitHub web UI).
3. GitHub Pages rebuilds automatically within a minute or two.
